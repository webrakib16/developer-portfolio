## 🚀 Getting Started

### 1) Clone

```bash
git clone https://github.com/webrakib16/developer-portfolio.git
cd developer-portfolio
```

### 2) Install

```bash
npm install
```

### 3) Run Locally

```bash
npm run dev
```

### 4) Build for Production

```bash
npm run build
```

## 🧩 Customize

To personalize this portfolio for yourself:

- Update **`src/config.ts`** — name, bio, social links, projects, skills, education
- Replace **`public/Rakib_Web_Developer_Resume.pdf`** with your own resume
- Swap out project images in **`public/images/`**
- Update **`index.html`** meta tags for SEO
